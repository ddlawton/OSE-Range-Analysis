New analysis (12/26/2025)

Overview

I checked how temperature varied across missions and regions. Fatick heated up through the sampling period, but Kaffrine, Thies, and Saint Louis were more stable. Saint Louis was generally colder than the other regions.

I then ran a GAM with a flexible smooth for temperature by region, including mission number and farmer as random effects. The trends were pretty similar to the original model, with the exception of some odd patterns at cooler temps.

To simplify, I also ran a model with temperature as the main variable and region/mission as random effects. In this case, both region and mission number came up significant for explaining OSE counts, but temperature and farmer had little effect.

Overall, it seems like temperature at the time of the survey isn’t a real driver for OSE counts once you control for region and mission—suggesting most of any pattern is noise or an artifact of timing/activity. I’m inclined to say temperature doesn’t need to be a focus in the main model, but happy to dig further if needed.

It looks like Fatick became hotter through the sampling period. Kaffrine, Thies, and Saint Louis seem more consistent between missions. Saint louis is definitely colder than the other three regions. So I would expect with the exception of Fatick, adding mission number to the model will not really add anything different.

The raw plots do not look very compelling, but let's construct a generalized additive model and see if there is a statistically significant trend.

```{r building-gam}
#| echo: false
#| message: false
#| warning: false

# Use model caching for the temperature GAM
mod <- cache_model(
    model_name = "locust_temperature_gam",
    data = data,
    fit_function = function(data) {
        mgcv::gam(
            ose_count ~
                s(temperature, region, bs = 'fs', k = 10) +
                s(farmer, bs = 're'),
            data = data,
            family = mgcv::tw(),
            select = TRUE
        )
    },
    # Simpler model for CI (reduced complexity)
    fit_function_simple = function(data) {
        mgcv::gam(
            ose_count ~
                s(temperature, region, bs = 'fs', k = 5) +
                s(farmer, bs = 're'),
            data = data,
            family = mgcv::tw(),
            select = TRUE
        )
    }
)
```
