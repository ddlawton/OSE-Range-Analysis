Summary

The goal of this page is to analyze locust density patterns across fertilizer treatments and regions. This analysis replicates key figures from the manuscript to ensure consistent theming and validates our data management approach. If you see errors, please let me know!

Locust density and region by treatment

To assess how locust count changes between treatment (fertilized and control) and region (four regions), I built a generalized linear mixed model (family: Poisson) per mission as follows:

\[ \begin{align*} \text{ose count}_{ij} =\ &\beta_0 \\ &+ \beta_1 \cdot \text{fertilizer treatment}_i \\ &+ \beta_2 \cdot \text{region}_i \\ &+ \beta_3 \cdot (\text{fertilizer treatment}_i \times \text{region}_i) \\ &+ u_j \\ &+ \varepsilon_{ij} \end{align*} \]

Where: - \(\text{ose count}_{ij}\): observed ose count for observation \(i\) from farmer \(j\) - \(\text{fertilizer treatment}_i\): fertilizer treatment group of observation \(i\) - \(\text{region}_i\): region of observation \(i\) - \((\text{fertilizer treatment}_i \times \text{region}_i)\): interaction between fertilizer treatment and region - \(u_j\): random effect for farmer \(j\), \(u_j \sim N(0, \sigma^2_{farmer})\) - \(\varepsilon_{ij}\): residual error

# Locust density and region by treatment

To assess how locust count changes between treatment (fertilized and control) and region (four regions), I built a generalized linear mixed model (family: Poisson) per mission as follows:

$$
\begin{align*}
\text{ose count}_{ij} =\ 
  &\beta_0 \\
  &+ \beta_1 \cdot \text{fertilizer treatment}_i \\
  &+ \beta_2 \cdot \text{region}_i \\
  &+ \beta_3 \cdot (\text{fertilizer treatment}_i \times \text{region}_i) \\
  &+ u_j \\
  &+ \varepsilon_{ij}
\end{align*}
$$

Where: - $\text{ose count}_{ij}$: observed ose count for observation $i$ from farmer $j$ - $\text{fertilizer treatment}_i$: fertilizer treatment group of observation $i$ - $\text{region}_i$: region of observation $i$ - $(\text{fertilizer treatment}_i \times \text{region}_i)$: interaction between fertilizer treatment and region - $u_j$: random effect for farmer $j$, $u_j \sim N(0, \sigma^2_{farmer})$ - $\varepsilon_{ij}$: residual error

```{r}
ose_dat <- data |>
  select(region, fertilizer_treatment, ose_count) |>
  mutate(region = factor(region, levels = c('Saint Louis', 'Thies', 'Fatick', 'Kaffrine')),
         fertilizer_treatment = factor(fertilizer_treatment, levels = c('fertilized', 'control'))) |>
  drop_na(ose_count, fertilizer_treatment) |>
```

# OSE count by treatment/region accounting for ground cover perent

The first test is to compare a model with ground cover and a model without ground cover. We will build both models per mission and then compare the estimated marginal means.


```{r}
library(patchwork)
plots <- list()
aic_results <- data.frame(
  mission_number = character(),
  AIC_with_gc = numeric(),
  AIC_without_gc = numeric(),
  best_model = character()
)

for (mission in unique(data$mission_number)) {
  dat_sub <- data |> dplyr::filter(mission_number == mission)
  mod_w_gc <- glmmTMB(
    ose_count ~ fertilizer_treatment * region + (1|farmer) + percent_ground_cover,
    data = dat_sub,
    family = tweedie()
  )
  mod2_wo_gc <- glmmTMB(
    ose_count ~ fertilizer_treatment * region + (1|farmer),
    data = dat_sub,
    family = tweedie()
  )
  # AIC comparison
  aic_with_gc <- AIC(mod_w_gc)
  aic_without_gc <- AIC(mod2_wo_gc)
  best <- ifelse(aic_with_gc < aic_without_gc, "with ground cover", "without ground cover")
  aic_results <- rbind(aic_results, data.frame(
    mission_number = mission,
    AIC_with_gc = aic_with_gc,
    AIC_without_gc = aic_without_gc,
    best_model = best
  ))
  # emmeans and plot
  mod_emms <- emmeans(mod_w_gc, ~ fertilizer_treatment * region, type = "response") |> 
    as_tibble() |> mutate(name = 'with ground cover', mission_number = mission)
  mod2_emms <- emmeans(mod2_wo_gc, ~ fertilizer_treatment * region, type = "response") |> 
    as_tibble() |> mutate(name = 'without ground cover', mission_number = mission)
  combined <- bind_rows(mod_emms, mod2_emms)
  combined$region <- factor(combined$region, levels = c("Kaffrine", "Thies", "Fatick", "Saint Louis"))

  p <- ggplot(combined, aes(x=region, y=response, color=fertilizer_treatment, shape=name)) +
    geom_point(position=position_dodge(width=0.4), size=6) +
    geom_errorbar(aes(ymin = asymp.LCL, ymax = asymp.UCL), position=position_dodge(width=0.4), width=0) +
    scale_color_manual(values = c("control" = "black", "fertilized" = "#006400")) +
    labs(title = paste("Mission", mission))
  plots[[as.character(mission)]] <- p
}

# Combine plots in one column (three rows)
(plots[[1]] / plots[[2]] / plots[[3]])

# Show AIC results
aic_results
```
